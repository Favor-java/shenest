# SheNest

SheNest is a beginner-friendly accommodation and roommate platform designed for women.

## Main features

- User registration and login
- Browse property listings
- Search and filter properties
- Save favorite properties
- Property image support
- Find roommate partners
- Contact property owners
- Reviews
- Booking requests
- Landlord dashboard
- Simple admin property verification

## Tech stack

### Frontend
- React
- Vite
- React Router
- Apollo Client

### Backend
- Node.js
- Express
- GraphQL
- Apollo Server

### Database
- PostgreSQL
- Prisma

### Authentication
- JWT
- bcrypt

## Project structure

```text
shenest/
├── client/     # React + Vite frontend
├── server/     # Express + GraphQL backend
└── README.md
```

The project intentionally uses simple, readable code and comments so that a beginner can follow how the frontend, GraphQL API, authentication, and database work together.
